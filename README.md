# Resume Parser AI

Resume Parser AI is a small project that extracts and normalizes resume text for downstream processing.

## Overview
- Simple frontend to upload resumes and view parsed results.
- Backend endpoints for parsing and storing correction history.

## Getting started
1. Install dependencies (backend/frontend) where applicable:

```powershell
cd resume-parser-ai/backend
npm install
cd ../frontend
npm install
```

2. Run backend and frontend (example):

```powershell
cd resume-parser-ai/backend
npm run dev
# in another terminal
cd resume-parser-ai/frontend
npm run dev
```

## Notes
- This repository may contain both backend and frontend folders; follow each subfolder's README for detailed setup.
- Add `.env` values (API keys, DB connection) as required.
